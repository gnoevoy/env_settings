data analytics key concepts
most of the topic similar to programming one

1. Data types: numbers (integer, decimal), strings, date's (date, time, timezone), boolean (true / false logic)
2. Data structures: single value, list, dictionary, tables

logical operations:
- equal = ; not equal <>
- greater, less < > ; equla or greater / less >= <=
- in - value existin in a list / dicitonary / table
- is - value is null, true, false 
- any / all -> any value is true or all value should be appropriate

number operations:
- math operations: plus, minus, multiple, divide, floor division (nearest whole number), modulo (reminder after divion), 
- rounding
- identify even or odd

text operations:
- replace substring 
- select by slicing indexes
- capitalize, make lowe case, trim spaces
- use regex patter to find values, replace or extract one

dates operations:
- extract part of date / time
- add two dates / time or number of days / hours ...
- find dates difference

list operations:
- extract value, delete value, add value, replace existing one's
- slicing by indexes
- lentht, aggreagtions (min, max, sum, average, count)
- sorting values
- pair together lists

dicionary operations:
- extract value, delete key, add new key, replace exisitng values
- lenght of dictionary, get keys, get values, 

tables operations:
- joins (inner, left, right ) by keys (two types of keys: unique and foreign) -> add columns from another tables
- unions (with duplicates or not) -> stack tables together
- selection of values
- sorting and filterings (filtering values or by values from expression)
- creating new columns (simple or with conditional logic)
- limiting number of rows
- make aggregations (simple one like sum, avg, min, max, count)
- ranking, offsets, previos / next values, ranges (with ordering and partitions by categories)

*also such transofrmations as: replacing value with dictionary one, removing duplicates, extracting unique values ...

3. loops -> go throught set of values (or columns) and perform specific tasks
4. error handling logic, wrap error in display some values or remove them
