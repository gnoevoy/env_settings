h - move left
l - move right
k - move up
j - move down

0 - move to the start of the line
$ - move to the end of the line

gg - start of a file
G - end of the file
ctrl + u - move up half a page
ctrl + d - move down half a page

zz - center line on screen
zt - move line to the top of the screen

w - move forward one word
e - move forward to the end of the word
b - move backward one word

f and t -> find value in a line (forward / backward)
*   search forward
#   search backward
n / N -> next or previous occurence


i - insert left
a - insert right
I - insert start of the line
A - insert end of the line
o - insert line below
O - insert line above

cc - delete entire line + insert mode
C - delete from cursor to the end of the line + insert mode
dd - delete entire line
D - delete from cursor to the end of the line

x - delete character
r - replace single character
s - delete chracter + insert mode


yy - copy entire line

p - paste
P - paste before cursor
J - join to lines together

v - visula mode
V - highligh entire line

~ - swap case under selection
U - apply upper or lower style
. - repeat last command

shift + > / < - indent / outdent selected lines (vscode thing)
